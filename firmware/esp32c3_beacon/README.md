# ESP32-C3 Super Mini BLE Beacon Firmware

Прошивка для тестового BLE-маяка на базе ESP32-C3 Super Mini для системы контроля присутствия.

## Возможности

- ✅ **iBeacon протокол** — полная совместимость с Apple iBeacon
- ✅ **Настраиваемые параметры** — UUID, Major, Minor, TX Power, интервал рекламы
- ✅ **BLE конфигурация** — настройка через BLE без необходимости перепрошивки
- ✅ **NVS хранилище** — сохранение настроек в энергонезависимой памяти
- ✅ **Совместимость с ТЗ** — реализация согласно `docs/intent/02_TEZ_Beacon.md`

## Технические характеристики

| Параметр | Значение |
|----------|----------|
| Микроконтроллер | ESP32-C3 Super Mini |
| Протокол | iBeacon (Apple) |
| Интервал рекламы | 100-10000 мс (по умолчанию 1000 мс) |
| TX Power | -40 ... +4 dBm |
| Хранилище | NVS (энергонезависимое) |
| Питание | USB 5V (для тестирования) |
| Потребление | ~20 мА |

## Установка среды разработки

### Вариант 1: PlatformIO (рекомендуется)

1. Установите [PlatformIO IDE](https://platformio.org/install/ide?install=vscode) в VS Code
2. Откройте папку `firmware/esp32c3_beacon` в VS Code
3. PlatformIO автоматически установит все зависимости
4. Подключите ESP32-C3 через USB
5. Нажмите "Upload" (→) для прошивки

### Вариант 2: Arduino IDE

1. Установите [Arduino IDE 2.x](https://www.arduino.cc/en/software)
2. Добавьте поддержку ESP32:
   - File → Preferences → Additional Boards Manager URLs
   - Добавьте: `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - Tools → Board → Boards Manager → установите "esp32 by Espressif Systems"
3. Установите библиотеку NimBLE:
   - Sketch → Include Library → Manage Libraries
   - Найдите и установите "NimBLE-Arduino"
4. Выберите плату: Tools → Board → ESP32C3 Dev Module
5. Настройки:
   - USB CDC On Boot: Enabled
   - USB Mode: Hardware CDC and JTAG
6. Загрузите все файлы из `src/` в Arduino IDE
7. Загрузите прошивку на плату

## Использование

### 1. Первая прошивка

При первой прошивке маяк получает настройки по умолчанию:
- **UUID:** `00010203-0405-0607-0809-0A0B0C0D0E0F`
- **Major:** 0
- **Minor:** 0
- **TX Power:** -59 dBm
- **Интервал:** 1000 мс

### 2. Проверка работы

1. Установите на телефон приложение **nRF Connect** ([Android](https://play.google.com/store/apps/details?id=no.nordicsemi.android.mcp), [iOS](https://apps.apple.com/app/nrf-connect/id1054362403))
2. Включите Bluetooth и начните сканирование
3. Найдите устройство с именем "ESP32" (или MAC-адресом)
4. Вы должны увидеть iBeacon пакет с UUID/Major/Minor

### 3. Конфигурация через BLE

#### Вариант А: Через nRF Connect

1. Подключитесь к маяку по BLE (кнопка "CONNECT")
2. Найдите сервис `12345678-1234-1234-1234-123456789abc`
3. Используйте characteristics для записи:
   - `...ab1` — UUID (16 байт)
   - `...ab2` — Major (2 байта, big-endian)
   - `...ab3` — Minor (2 байта, big-endian)
   - `...ab4` — TX Power (1 байт, signed)
   - `...ab5` — Interval (2 байта, big-endian, мс)
   - `...ab8` — Reset to defaults (запишите `0xAA`)
4. После записи настроек маяк автоматически перезапустит рекламу
5. Настройки сохраняются в NVS и переживают перезагрузку

#### Вариант Б: Через веб-конфигуратор (будет реализован)

В будущем планируется веб-приложение для удобной настройки маяков.

### 4. Массовое развёртывание

Для настройки партии маяков:

1. Прошейте все маяки одинаковой прошивкой
2. Для каждого маяка:
   - Подключитесь по BLE
   - Запишите уникальные UUID/Major/Minor
   - Маяк автоматически сохранит настройки
3. Зарегистрируйте маяки в админ-панели (MAC-адрес + UUID)

### 5. Калибровка TX Power

1. Встаньте на расстоянии 1 метр от маяка
2. Измерьте RSSI через nRF Connect
3. Запишите значение в TX Power characteristic
4. Теперь маяк будет передавать корректное значение для определения расстояния

## BLE сервисы

### iBeacon Advertisement
- **Формат:** Apple iBeacon
- **Компания:** Apple Inc. (0x004C)
- **Тип:** 0x0215 (iBeacon)
- **Данные:** UUID (16 байт) + Major (2) + Minor (2) + TX Power (1)

### Configuration Service
- **UUID:** `12345678-1234-1234-1234-123456789abc`

| Characteristic | UUID | Тип | Описание |
|----------------|------|-----|----------|
| UUID | `...ab1` | R/W | Proximity UUID (16 байт) |
| Major | `...ab2` | R/W | Major ID (2 байта) |
| Minor | `...ab3` | R/W | Minor ID (2 байта) |
| TX Power | `...ab4` | R/W | TX Power (1 байт, dBm) |
| Interval | `...ab5` | R/W | Интервал рекламы (2 байта, мс) |
| Battery | `...ab6` | R | Уровень батареи (1 байт, %) |
| Firmware | `...ab7` | R | Версия прошивки (2 байта) |
| Reset | `...ab8` | W | Сброс к заводским настройкам (0xAA) |

## Энергопотребление

| Режим | Ток |
|-------|-----|
| BLE реклама (1000 мс) | ~20 мА |
| BLE подключение | ~30 мА |
| Deep sleep | ~5 мкА |

**Важно:** При питании от USB (повербанк) маяк может работать неограниченно долго. Для автономной работы от CR2032 необходима оптимизация (deep sleep между рекламными событиями).

## Отладка

### Serial Monitor
Подключитесь к маяку через USB и откройте Serial Monitor (115200 baud):
- При загрузке выводится текущая конфигурация
- При изменении настроек выводятся сообщения об обновлениях
- MAC-адрес устройства для идентификации

### LED индикация
- **2 мигания при старте** — успешная инициализация
- **5 миганий** — готов к работе
- **3 мигания** — конфигурация изменена
- **1 мигание каждые 5 сек** — маяк работает

## Известные ограничения

1. **Два BLE режима:** Маяк одновременно рекламирует iBeacon и Configuration Service. Это может вызвать конфликты. В будущих версиях планируется разделение режимов.

2. **Нет телеметрии батареи:** ESP32-C3 не имеет встроенного ADC для измерения напряжения батареи. Для реальной телеметрии необходимо добавить внешнюю схему.

3. **Нет deep sleep:** Текущая версия не использует deep sleep для экономии энергии. Для автономной работы необходимо добавить циклы сна.
