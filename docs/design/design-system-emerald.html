📖 Рекомендации по использованию

Основные принципы

  • ✓一致性: Используйте единые цвета и отступы во всем приложении
  • ✓ Контраст: Убедитесь, что текст хорошо читается на фоне (WCAG AA)
  • ✓ Иерархия: Используйте разные размеры шрифтов для создания визуальной иерархии
  • ✓ Состояния: Всегда показывайте состояния элементов (hover, active, disabled)

Когда использовать цвета

  • Primary Основные действия, ссылки, активные состояния
  • Neutral Текст, фоны, границы, неактивные элементы
  • Success Успешные операции, положительные статусы
  • Warning Предупреждения, требования внимания
  • Error Ошибки, опасные действия, отрицательные статусы
